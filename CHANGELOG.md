# Changelog

## v1.0.0 — первый релиз

- Offline-first Room database.
- Ручной конструктор тренировок и пресеты Full Body A/B/C.
- Автозаполнение по прошлой завершённой тренировке.
- Тоннаж, длительность, фактический отдых и rest timer.
- Локальные JSON/CSV backup и восстановление.
- Google Drive sync через WorkManager.
- Расширенный каталог упражнений с нормализованными названиями.
- Обновлённый dashboard для S24 Ultra.
- Android Emulator для UI-проверки без телефона.
- About screen и подготовленная проверка GitHub Releases.
