# Changelog

## v1.1.1 — синхронизация данных

- Добавлена синхронизация личных данных с Google Drive.
- Автоматическая синхронизация запускается только при включённом переключателе.
- В синхронизацию входят тренировки, планы и настройки прогрессии.

## v1.1.0 — синхронизация и управление тренировкой

- Google Drive sync payload теперь включает настройки прогрессии и назначенные планы на главной.
- Слияние локальных и облачных данных сохраняет более новую версию записи по `updatedAt`.
- История открывается в подробном режиме: упражнения, подходы, вес, повторения, запас и отдых.
- Планы и упражнения перед стартом можно менять местами долгим нажатием и перетаскиванием.
- Количество подходов на упражнение настраивается от 1 до 12.
- Упражнение можно заменить прямо во время активной тренировки.
- Вес подхода вводится вручную через числовую клавиатуру с десятичными значениями.
- На главную можно назначать собственные планы.

## v1.0.0 — первый релиз

- Offline-first Room database.
- Ручной конструктор тренировок и пресеты Full Body A/B/C.
- Автозаполнение по прошлой завершённой тренировке.
- Тоннаж, длительность, фактический отдых и rest timer.
- Локальные JSON/CSV backup и восстановление.
- Google Drive sync через WorkManager.
- Расширенный каталог упражнений с нормализованными названиями.
- Обновлённый dashboard для S24 Ultra.
- Android Emulator для UI-проверки без телефона.
- About screen и подготовленная проверка GitHub Releases.
