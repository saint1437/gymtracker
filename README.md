# GymTracker

Офлайн-first трекер силовых тренировок на Kotlin, Jetpack Compose Material 3 и Room.

## Возможности

- 73 упражнения в русскоязычном каталоге;
- группы мышц: ноги, икры, пресс, грудь, спина, плечи, бицепс и трицепс;
- Full Body A/B/C и собственные планы;
- редактирование плана перед стартом;
- добавление упражнений во время тренировки;
- автозаполнение веса и повторений по прошлой тренировке;
- подсказки прибавки веса;
- тоннаж, длительность, отдых и история тренировок;
- локальная резервная копия JSON и экспорт CSV;
- необязательная синхронизация с Google Drive;
- тёмная тема и крупные touch-targets для тренировки без клавиатуры.

## Сборка

Требования: Android Studio с JDK 17 и Android SDK Platform 35.

```powershell
.\gradlew.bat test
.\gradlew.bat assembleDebug
```

APK создаётся в `app/build/outputs/apk/debug/app-debug.apk`.

Для установки на подключённое Android-устройство:

```powershell
.\build-and-install.ps1
```

Для запуска в эмуляторе Android:

```powershell
.\run-on-emulator.ps1
```

Скрипты используют `JAVA_HOME`, `ANDROID_SDK_ROOT` и `GRADLE_HOME`. Если переменные не заданы, инструменты должны быть доступны через `PATH`.

## Резервные копии и экспорт

Резервная копия и экспорт доступны в разделе «Настройки». CSV сохраняет фиксированные заголовки для последующего анализа.
